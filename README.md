# VTM Random Enemy Generator

Модуль Foundry VTT (v13–14) для системы [World of Darkness 5e](https://github.com/WoD5E-Developers/wod5e).

Добавляет на панель токенов кнопку с черепом: она открывает предпросмотр случайного вампира-противника
(клан, стиль охоты, атрибуты, навыки, дисциплины) с выбором сложности и создаёт актёра типа `vampire`.
